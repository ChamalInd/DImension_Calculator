# Dimension Calculator

### Project Overview

A Simple apllication to calculate physical dimensions like area and volume of both 2D and 3D objects.

### Features
- Calculates dimensions in 2D objects
- Calculates dimensions in 3D objects
- Provides equations and visual reprentations
- Interactive UI

### Tech Stack
- Language: Python
- Library: PyQt5

### Project Structure
- `main.py`: The main controller containing the function to start the program
- `requirements.txt`: File containing all the required python libreries
- `assets`
    - `data`: Contains all the relevant data of the application
    - `images`: Contains all the images used in the application
    - `scripts`
        - `app.py`: Contains all the UI elements and logic of the application
        - `variables.py`: Contains all the variables used by the application


### Getting Started

#### Prerequisites
- Make sure you have Python installed. You can check by running,
```
python --vesion
```

#### Installation
- Clone the project to your system
    ```
    git clone
    cd Dimension_Calculator
    ```
- Then install all the requirements
    ```
    pip install -r requirement.txt
    ```

#### Running the App
- Run 
```
python main.py
```
